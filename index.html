اكتشف مسارك

السؤال 1/4

تخيّل إنك تبدأ يومك بمهمة “مستحيلة” بسرعة — شو بتحب تكون؟

أ) اللي بيفهم ويحلّل المشكلة خطوة بخطوة
ب) اللي بيصمّم ويبتكر حلول بشكل عملي ومرئي
ج) اللي بيتواصل ويقنع الناس ويرتّب الأفكار
د) اللي بيدير وينظّم الفريق والوقت والموارد

لما لازم تختار بسرعة وما كلشي واضح… شو بتعمل غالباً؟

أ) ببحث عن النمط والأسباب
ب) بجرب أفكار جديدة بسرعة
ج) بسمع للناس وأوازن وجهات النظر
د) بضع خطة وهدف وأقيس التقدّم

أي نشاط بتحس إنك “بتنسجم معه” حتى لو تخيّلياً؟

أ) كتابة / تفكير / تجميع معلومات وتحليلها
ب) إنشاء محتوى / تصميم / برمجة / بناء مشاريع
ج) تدريب / تقديم / تواصل / عمل مع جمهور
د) تنظيم حملات / إدارة مشاريع / متابعة سير العمل

تخيّل إنك مواجه تحدّي خلال أسبوع… شو أكتر حصيلة بتحبها؟

أ) حلّ دقيق لمسألة أو تحسين أداء
ب) شيء جديد طلع للواقع (مشروع / منتج / تصميم)
ج) تغيير في الناس (تعليم / إقناع / تأثير)
د) نتيجة منظّمة (خطة تمشي + أرقام تتحسّن)
